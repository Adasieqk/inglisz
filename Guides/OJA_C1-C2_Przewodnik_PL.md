## 0.3 Zasady transformacji — co naprawdę mówi oficjalny test przykładowy

## MODUŁ 1 — INWERSJA

**Inwersja = operator (czasownik posiłkowy) PRZED podmiotem** (szyk pytający) w zdaniu oznajmującym — wywołana przez wysunięty na początek element przeczący/ograniczający, okres warunkowy lub zabieg stylistyczny.

### 1.1 Przysłówki przeczące i ograniczające

**Wzór:** `Wyrażenie przeczące + OPERATOR + PODMIOT + czasownik główny`
Brak operatora w zdaniu wyjściowym? Dodaj **do/does/did** (a po nim **bezokolicznik bez „to”**).

| Wyzwalacz | Zdanie wzorcowe | Uwaga |
|---|---|---|
| Never (before) | **Never have I seen** such chaos. | |
| Rarely / Seldom (, if ever,) | **Seldom, if ever, does she** complain. | |
| Little | **Little did they know** what awaited them. | zawsze *did + know/realise/suspect* |
| Hardly / Scarcely / Barely … **when/before** | **Hardly had we sat down when** the phone rang. | past perfect + **when** (nigdy *than*) |
| No sooner … **than** | **No sooner had he left than** it started to pour. | past perfect + **than** (nigdy *when*) |
| Not only … but (also) | **Not only did he lie, but he also** forged documents. | inwersja tylko w **pierwszym** zdaniu |
| Not until + czas/zdanie | **Not until 2005 did** the truth emerge. | inwersja w zdaniu **głównym** |
| Only + okolicznik | **Only then / later / recently / in this way / by doing X** did/can… | |
| Only when / after / if + zdanie | **Only when the results arrived did we** celebrate. | inwersja w zdaniu **głównym** |
| At no time | **At no time were** the prisoners told. | ≠ *in no time* (= bardzo szybko, **bez** inwersji) |
| On no account | **On no account must you** open it. | liczba pojedyncza *account* |
| Under no circumstances | **Under no circumstances should** you sign. | liczba mnoga *circumstances* |
| In no way / By no means / In no sense | **In no way is this** acceptable. | |
| Nowhere (else) | **Nowhere else will you find** such views. | |
| Not once / Not for a moment | **Not once did she** look back. | |
| Not a + rzeczownik (wysunięte dopełnienie) | **Not a word did he say.** | |
| No longer | **No longer do we** accept cash. | |
| Not since | **Not since the 1960s has the party** won so many seats. | |
| So + przymiotnik/przysłówek … that | **So violent was the storm that** flights were cancelled. | |
| Such + be … that | **Such was the demand that** the site crashed. | *such* + *be* + fraza rzeczownikowa |
| Neither / Nor | She can't swim, **nor can her brother**. | |

**Kiedy NIE robić inwersji**

| Sytuacja | Poprawnie (bez inwersji) |
|---|---|
| Słowo przeczące należy do **podmiotu** | **Hardly anyone** came. / **Not many people** know. / **Only Tom** knew. |
| *In no time* (= szybko) | We were home **in no time**. |
| *Not long ago* (znaczenie nieprzeczące) | **Not long ago** I met her. |
| Wyrażenie nie stoi na początku | I have **never** seen such chaos. / He **not only** lied **but also**… |
| Stały zwrot *Not only that,* | **Not only that, but** he was late too. |

**Pułapki „natywne”**

| ✗ Brzmi naturalnie | ✓ Odpowiedź egzaminacyjna | Dlaczego |
|---|---|---|
| No sooner had I arrived **when** she left. | …**than** she left. | korelat jest stały |
| Hardly had I arrived **than**… | …**when/before**… | |
| Only when he left **I realised**. | …**did I realise**. | inwersja w zdaniu głównym |
| Not until **did I see** the news I realised. | Not until I saw the news **did I realise**. | odwrócone złe zdanie |
| Little **did I knew**. | Little did I **know**. | po *did* forma podstawowa |
| Never **I have** seen… | Never **have I** seen… | |
| **Became the fraud** apparent. | **Did the fraud become** apparent. | czasowniki leksykalne wymagają *do* |
| Under no **circumstance**… | Under no **circumstances**… | stała liczba mnoga |
| On **any** account… | On **no** account… | |

### 1.2 Inwersja w okresach warunkowych (bez *if*)

| Typ | Z *if* | Z inwersją | Przeczenie z inwersją |
|---|---|---|---|
| 1. (mało prawdopodobna przyszłość) | If you **should** need help… | **Should you need** help… | **Should you not** wish to… |
| 2. | If I **were** rich… / If he **were to** resign… | **Were I** rich… / **Were he to resign**… | **Were it not for** your help… |
| 3. | If I **had** known… | **Had I known**… | **Had it not been for** you… |
| Mieszany (przeszłość → teraźniejszość) | If I had taken the job, I'd be in Paris now. | **Had I taken** the job, I would be in Paris now. | |
| Mieszany (teraźniejszość → przeszłość) | If I weren't so busy, I'd have come. | **Were I not** so busy, I would have come. | |

**Żelazne zasady**

1. Inwersję tworzą tylko **had / were / should**. ✗ *Was I to…* ✗ *Would I…*
2. **Nigdy** nie skracaj przeczenia w inwersji: ✗ *Hadn't it been for…* ✓ *Had it not been for…*
3. **Nigdy** nie łącz *if* z inwersją: ✗ *If should you need…*
4. *Were* + bezokolicznik z **to** dla hipotetycznych czynności: ✓ *Were the government **to raise** taxes…*

### 1.3 Inwersja przyzwalająca („wysunięty przymiotnik + as/though”)

**Wzór:** `Przymiotnik / Przysłówek / Rzeczownik (bez przedimka) + as/though + podmiot + czasownik`

| Wzór | Uwagi |
|---|---|
| **Tired as I was**, I kept working. | = Although I was tired |
| **Hard though she tried**, she failed. | |
| **Much as I admire** her, I disagree. | bardzo częste w transformacjach |
| **Try as he might**, he couldn't open it. | stałe: *Try as + podmiot + might/may* |
| **Child though he was**, he understood. | **bez przedimka** przy rzeczowniku |
| **Strange as it may seem**, it's true. | |
| **However hard** he tries, … / **No matter how** hard… | to nie inwersja, ale to samo znaczenie |
| **For all** his wealth, he was lonely. | = mimo |
| **Be that as it may**, … / **Come what may**, … | skamieniały subjunctive |

**Pułapki „natywne”**

- ✗ *As tired as I was, I kept working.* — częste w mowie (zwł. AmE), ale ryzykowne w kluczu preskryptywnym. Pisz **Tired as I was**.
- ✗ *As he was young, he understood* — tu *as* znaczy **ponieważ**: znaczenie się zmienia.
- ✗ *A child as he was…* — usuń przedimek.
- ✗ *However he tried hard* → ✓ *However hard he tried*.

### 1.4 Inwersja stylistyczna i miejscowa (czasownik główny przed podmiotem)

| Wzór | Przykład | Ograniczenie |
|---|---|---|
| Okolicznik miejsca/kierunku + czasownik nieprzechodni | **Into the room burst** a policeman. / **On the hill stood** a castle. | tylko podmiot **rzeczownikowy**: *Off **they** went* (z zaimkiem bez inwersji) |
| *Here/There* + come/go | **Here comes** the bus. / **Here it comes.** | zaimek → bez inwersji |
| Wysunięty imiesłów/przymiotnik + *be* | **Gone are the days** when… / **Attached is** my CV. / **Especially worrying is** the cost. | formalne |
| Czasownik relacjonujący po mowie niezależnej | "Stop!" **said the officer.** | ✗ *said he* (archaizm) |
| Porównania (formalne, opcjonalne) | She earns more **than does** her husband. / …**as did** his father. | nie z podmiotem zaimkowym |
| Krótkie odpowiedzi *So / Neither / Nor* | I've finished, and **so has she**. | *So it is!* = zdziwione potwierdzenie (bez inwersji) |

### 1.5 Bonus: szyk „so/too/as/how + przymiotnik + a + rzeczownik”

✓ *It was **too difficult a task**.* ✓ *She's **as good a player as** her sister.* ✓ ***So beautiful a city**…* ✓ ***How big a problem** is it?*
✗ *too difficult **of** a task* (potoczne AmE) ✗ *a too difficult task*

## MODUŁ 2 — OKRESY WARUNKOWE, „UNREAL PAST” I SUBJUNCTIVE

### 2.1 Pełna mapa okresów warunkowych

| Typ | Zdanie z *if* | Zdanie główne | Użycie |
|---|---|---|---|
| Zerowy | present | present | prawdy ogólne |
| 1. | present | will / modal + bezokol. | realna przyszłość |
| 2. | past simple / **were** | would/could/might + bezokol. | nierealna teraźniejszość/przyszłość |
| 3. | past perfect | would/could/might **have + III forma** | nierealna przeszłość |
| Mieszany A | past perfect | would + bezokol. (**teraz**) | przyczyna w przeszłości → skutek teraz |
| Mieszany B | past simple / were | would **have + III forma** | stała cecha → skutek w przeszłości |

> **Mieszany A:** *If I **had accepted** the offer, I **would be living** in Dublin now.*
> **Mieszany B:** *If she **weren't** so shy, she **would have spoken** up yesterday.*

### 2.2 *Will/would* w zdaniu z *if* — kiedy jest poprawne

| Dozwolone użycie | Przykład |
|---|---|
| Uprzejmość | *If you **will/would** wait here, I'll fetch the manager.* |
| Upór / irytujący nawyk (z akcentem) | *If you **will** keep eating junk, you'll get ill.* |
| Skutek jest powodem działania | *If it **will** help, I'll lend you the money.* |
| ✗ Błąd natywny | ✗ *If I **would have** known…* → ✓ *If I **had** known…* |

### 2.3 Zamienniki *if*

| Wyrażenie | Znaczenie / konstrukcja |
|---|---|
| unless | = if … not (✗ *unless you don't*) |
| provided / providing (that), as/so long as, on condition that | silny warunek |
| in case | **środek ostrożności, nie warunek**: *Take an umbrella **in case** it rains* ≠ *if it rains* |
| in the event of + rzeczownik / in the event that + zdanie | formalne |
| suppose / supposing / what if / imagine | + past dla sytuacji nierealnych |
| but for + rzeczownik | = if it were not / had not been for |
| otherwise / or else | *Hurry, **otherwise** we'll miss it.* |
| even if / only if | *Only if* + inwersja w zdaniu głównym |
| given (that), assuming (that) | |
| if need be, if in doubt, if so, if not, if anything | zwroty stałe |

### 2.4 Wish / If only

| Czas | Forma | Przykład |
|---|---|---|
| Stan teraźniejszy | wish + past simple / **were** | *I wish I **were** taller.* |
| Umiejętność teraz | wish + **could** | *I wish I **could** drive.* |
| Żal o przeszłość | wish + **past perfect** / could have + III forma | *I wish I **had listened**.* |
| Irytacja / chęć zmiany (**ktoś lub coś innego**) | wish + **would** + bezokol. | *I wish you **would** stop.* / *I wish it **would** rain.* |
| Formalne „chcieć” | wish + **to** + bezokol. | *I wish **to** complain.* |

**Pułapki:** ✗ *I wish I would have…* · ✗ *I wish I would stop* (użyj *could*) · ✗ *I wish I was* (potoczne → na teście **were**) · ✗ *I wish she would be taller* (stany nie łączą się z *would*).

### 2.5 Would rather / would sooner / had better / prefer

| Wzór | Przykład |
|---|---|
| Ten sam podmiot → **bezokolicznik bez to** | *I'd rather **stay**.* / *I'd rather **not** say.* |
| Inny podmiot → **past simple** (znaczenie teraźniejsze/przyszłe) | *I'd rather you **didn't** smoke here.* |
| Inny podmiot → **past perfect** (znaczenie przeszłe) | *I'd rather you **hadn't told** her.* |
| would rather X **than** Y (obie formy bez to) | *I'd rather walk **than** take the bus.* |
| had better + bezokol. bez to | *You **had better not** be late.* ✗ *had better **to*** |
| prefer **-ing to -ing** | *I prefer walking **to** cycling.* |
| prefer **to** + bezokol. **rather than** + bezokol. bez to | *I prefer to walk **rather than** cycle.* |
| would prefer sb **to** do / would prefer **it if** sb **did** | *I'd prefer **it if** you **left**.* |

✗ *I'd rather you **don't*** · ✗ *I'd rather you **to** leave* · amerykańskie *I'd rather you **not** go* to wariant subjunctive — **nie** jest oczekiwaną odpowiedzią.

### 2.6 It's time / It's high time / It's about time

- ✓ *It's (high/about) time **we left**.* (past simple, znaczenie teraźniejsze — „już najwyższa pora”)
- ✓ *It's time **for us to leave**.* / *It's time **to leave**.*
- ✗ *It's high time we **leave**.* ✗ *…we **should** leave.* ✗ *…we **had left**.*

### 2.7 As if / as though

- Realna możliwość → normalny czas: *It looks **as if** it**'s going to** rain.*
- Nierealne → past / **were**: *He talks **as if** he **owned** the place.* / *…as if he **were** the boss.*
- ✗ *It looks **like** it's going to rain* (potoczne — w zadaniach formalnych *as if*).

### 2.8 Subjunctive „nakazowy” (ulubieniec transformacji)

**Wzór:** `czasownik / przymiotnik / rzeczownik wyrażający żądanie + that + podmiot + BEZOKOLICZNIK BEZ TO` (bez -s, bez następstwa czasów, przeczenie = *not* + forma podstawowa)

| Wyzwalacze | Przykład |
|---|---|
| **Czasowniki:** advise, ask, beg, demand, insist, order, propose, recommend, request, require, stipulate, **suggest**, urge | *She **suggested that** the meeting **be postponed**.* |
| **Przymiotniki:** essential, imperative, vital, crucial, important, necessary, advisable, desirable | *It is **essential that** he **be** informed.* |
| **Rzeczowniki:** demand, proposal, recommendation, requirement, insistence | *the **requirement that** every candidate **sign** in* |
| Przeczenie | *We recommend **that** the plan **not be** adopted.* |
| Alternatywa brytyjska | *…that the meeting **should be** postponed.* ✓ |

**Pułapki:** ✗ *suggest **him to** go* · ✗ *suggested **to** postpone* · ✗ *insisted that she **leaves*** (potoczne BrE; na teście **leave / should leave**).
**Pułapka znaczeniowa:** *He insisted that he **was** innocent* = upierał się, twierdził (tryb oznajmujący) ≠ *He insisted that she **be** present* = zażądał.

**Skamieniałe formy subjunctive do rozpoznania:** *God save the King · Long live… · Be that as it may · Come what may · Suffice it to say · So be it · Far be it from me to… · If need be · Heaven forbid · As it were · Truth be told · Woe betide…*

## MODUŁ 3 — CZASOWNIKI MODALNE W PRZESZŁOŚCI

### 3.1 Tabela główna

| Forma | Funkcja | Przykład |
|---|---|---|
| **must have + III forma** | pewność TAK (dedukcja) | *She **must have left** — her coat's gone.* |
| **can't / couldn't have + III forma** | pewność NIE | *He **can't have written** this — he can't spell.* |
| **may / might / could have + III forma** | możliwość | *They **might have missed** the bus.* |
| **might / could have + III forma** (kontrfaktycznie) | było możliwe, ale się nie stało | *You **could have been** killed!* |
| **should / ought to have + III forma** | krytyka, żal (nie zrobiono) | *You **should have told** me.* |
| **shouldn't / ought not to have + III forma** | krytyka (zrobiono) | *I **shouldn't have eaten** that.* |
| **should have + III forma** (oczekiwanie) | powinno już nastąpić | *They **should have arrived** by now.* |
| **needn't have + III forma** | **zrobiono**, ale niepotrzebnie | *We **needn't have booked** — it was empty.* |
| **didn't need to + bezokol.** | nie było potrzeby (zwykle **nie zrobiono**) | *We **didn't need to book**, so we didn't.* |
| **didn't have to + bezokol.** | brak obowiązku | *I **didn't have to** wear a uniform.* |
| **would have + III forma** | nierealny skutek w przeszłości | *I **would have helped**.* |
| **wouldn't + bezokol.** (przeszłość) | odmowa | *The door **wouldn't open**.* |
| **will have + III forma** | pewne przypuszczenie o przeszłości | *You **will have heard** the news.* |
| **was/were supposed to + bezokol.** | planowane/oczekiwane, nie doszło do skutku | *I **was supposed to** call her.* |
| **was/were to have + III forma** | formalny niezrealizowany plan | *The ceremony **was to have taken** place in May.* |
| **might as well have + III forma** | i tak nie zrobiłoby różnicy | *We **might as well have stayed** at home.* |
| **may/might well have + III forma** | całkiem prawdopodobne, że | *She **may well have forgotten**.* |
| **would rather have + III forma** | preferencja w przeszłości | *I'd **rather have gone** to the cinema.* |

### 3.2 Pułapki „natywne”

| ✗ | ✓ | Zasada |
|---|---|---|
| He **mustn't have** heard. | He **can't/couldn't have** heard. | *mustn't* = zakaz w BrE; *must not have* to AmE |
| You **needn't have to** come. | You **needn't have come** / **didn't need to come**. | nigdy *needn't have to* |
| We **didn't need to have** booked. | We **needn't have booked**. | |
| I **could of** gone. | I **could have** gone. | pisownia słabej formy /əv/ |
| You **should have went**. | You **should have gone**. | III forma (błąd dialektalny!) |
| After hours, we **could find** the key. | …we **managed to / were able to** find it. | jednorazowy sukces w przeszłości ≠ *could* (przeczenia i zmysły są OK: *couldn't find*, *could see*) |
| The patient **may have** survived if the ambulance had come. (zmarł) | …**might have** survived… | kontrfaktycznie = *might/could*, nie *may* |
| **Can** have he forgotten? | **Could** he have forgotten? | |

### 3.3 Inne punkty C2

- ***Should* „przypuszczające”:** *It's odd that he **should** say that.* / *Who **should** walk in but my ex!*
- **Modalne *need*** (formalne BrE, tylko przeczenia i pytania, bez *-s*, bezokol. bez to): ***Need** I remind you…?* / *He **needn't** come.*
- **Dare:** *How **dare** you!* / *I **dare say*** (= przypuszczam) / *She **daren't** tell him.*
- ***Shall*** w tekstach prawnych: *The tenant **shall** pay…*
- ***Would*** dla typowego (irytującego) zachowania: *He **would** say that, wouldn't he?*
- **Strona bierna z modalnymi w przeszłości:** *must have been stolen · should have been told · can't have been seen*

## MODUŁ 4 — STRUKTURY ZŁOŻONE I WZORCE CZASOWNIKOWE

### 4.1 Siatka bezokoliczników i gerundiów

| | Czynna | Bierna |
|---|---|---|
| Bezokolicznik prosty | to do | to be done |
| Bezokolicznik ciągły | to be doing | (to be being done — unikaj) |
| Bezokolicznik dokonany | to have done | to have been done |
| Bezokolicznik dokonany ciągły | to have been doing | — |
| Gerund | doing | being done |
| Gerund dokonany | having done | having been done |

### 4.2 Complex subject (bierna konstrukcja relacjonująca) — transformacja nr 1

**Dwa wzory:**
- `It + is/was + said/believed/thought… + that + zdanie`
- `Podmiot + is/was + said/believed/thought… + BEZOKOLICZNIK Z TO`

**Czasowniki:** say, believe, think, know, consider, report, expect, allege, assume, estimate, presume, rumour (tylko bierna), suppose, understand, fear, acknowledge.

**Mapa czasów (czasownik relacjonujący w teraźniejszym: „People believe…”)**

| Zdanie wyjściowe | Complex subject |
|---|---|
| …that he **is** hiding. | He is believed **to be hiding**. |
| …that he **lives** abroad. | He is believed **to live** abroad. |
| …that he **left / has left / had left**. | He is believed **to have left**. |
| …that he **has been working**… | He is believed **to have been working**… |
| …that the money **was stolen**. | The money is believed **to have been stolen**. |
| …that he **will win**. | He is **expected to win**. / It is thought that he will win. |
| …that there **were** survivors. | There are believed **to have been** survivors. |

> **Złota zasada:** bierny czasownik relacjonujący zachowuje **czas oryginału** (*believe* → *is believed*; *believed* → *was believed*); bezokolicznik pokazuje, czy relacjonowane zdarzenie jest **równoczesne** (*to be*), czy **wcześniejsze** (*to have been*).
> **Pułapka z *there*:** *there* uzgadnia się z **rzeczywistym** podmiotem: *There **are** thought to have been **hundreds** of people…*

**Czasowniki „podnoszące”** (ta sama logika): *seem, appear, happen, turn out, prove, tend* + *to* + bezokol.; *be likely/unlikely/certain/sure/bound/due/set/about* + *to* + bezokol.
*It turned out that he had lied* → *He **turned out to have lied**.* · *It happened that I was there* → *I **happened to be** there.*

### 4.3 Complex object i zasada „w stronie biernej wraca *to*”

| Czynna | Bierna | Uwaga |
|---|---|---|
| They **made** him **wait**. | He **was made to wait**. | wraca *to* |
| I **saw** her **enter**. | She **was seen to enter**. / **seen entering** | wraca *to* |
| They **let** him **go**. | He **was allowed to go**. | *let* nie ma zwykłej strony biernej (idiomy: *be let go*, *be let off*) |
| They **helped** us (**to**) move. | We **were helped to move**. | |
| I **want** you **to** go. / I'd **like** it **to** be done. | — | ✗ *I want that you go* |
| I **consider** him (**to be**) the best. | He **is considered** (**to be**) the best. | formalne |
| They **allow** us **to** smoke. / They **allow smoking**. | We **are allowed to** smoke. / Smoking **is allowed**. | *allow/permit/forbid/advise/recommend* + **-ing** bez dopełnienia, **to** + bezokol. z dopełnieniem |

**Formalne *it* jako dopełnienie (strefa błędów natywnych):** ✓ *I'd appreciate **it** if you could…* ✗ *I'd appreciate if you could…* · ✓ *I take **it** that…* · ✓ *I hate **it** when…* · ✓ *She made **it** clear that…* · ✓ *I find **it** hard to believe…*

### 4.4 Konstrukcje kauzatywne

| Konstrukcja | Znaczenie | Przykład |
|---|---|---|
| **have** + dopełnienie + **III forma** | zlecenie usługi | *I **had my hair cut**.* |
| **have** + dopełnienie + **III forma** | spotkało cię coś złego | *She **had her flat broken into**.* (partykuła zostaje!) |
| **get** + dopełnienie + **III forma** | załatwić / zdołać dokończyć | *I need to **get this report finished**.* |
| **have** + osoba + **bezokol. bez to** | polecenie (z pozycji władzy) | *I'll **have my assistant call** you.* |
| **get** + osoba + **to** + bezokol. | przekonać | *I **got him to lower** the price.* |
| **make** + osoba + **bezokol. bez to** | zmusić | *She **made me apologise**.* |
| **have** + osoba + **-ing** | wywołać trwający efekt | *He **had us laughing** all night.* / *I **won't have you speaking** like that.* |
| **get** + dopełnienie + **-ing** | uruchomić coś | *I **got the engine running**.* |
| **need/want + -ing** | znaczenie bierne | *The car **needs washing** / **needs to be washed**.* |
| make oneself + III forma | | *make oneself **understood / heard*** |

### 4.5 Gerund vs bezokolicznik — zmiana znaczenia

| Czasownik | + -ing | + to + bezokol. |
|---|---|---|
| remember / forget | pamięć o przeszłej czynności | pamiętać o obowiązku |
| regret | żałować przeszłości | *We regret **to inform** you* (formalne ogłoszenie) |
| try | eksperymentować | starać się |
| stop | przestać | zatrzymać się, żeby |
| go on | kontynuować to samo | przejść do czegoś nowego |
| mean | oznaczać, wiązać się z | zamierzać |
| need | sens bierny (*needs fixing*) | konieczność |
| propose | proponować | zamierzać |
| be afraid | strach przed tym, co może się stać | zbyt przestraszony, by działać |

### 4.6 *To* + -ING (pułapka przyimkowa)

`look forward to · object to · be/get used to · be accustomed to · be committed to · be devoted/dedicated to · be opposed to · admit to · confess to · in addition to · with a view to · when it comes to · take to · resort to · prior to · the key to · come close to`

✗ *I look forward to **hear*** · ✗ *He's used to **work** late* · ✗ *with a view to **buy***

### 4.7 Wzorce czasowników relacjonujących (podstawa transformacji)

| Wzór | Czasowniki |
|---|---|
| czasownik + **to** + bezokol. | agree, offer, refuse, promise, threaten, claim, pretend, decline, vow |
| czasownik + **dopełnienie + to** + bezokol. | advise, urge, persuade, remind, warn, encourage, beg, invite, order, forbid, instruct, implore |
| czasownik + **-ing** / **having + III forma** | deny, admit (to), suggest, recommend, regret, mention, propose |
| czasownik + **przyimek + -ing** | apologise **for**, insist **on**, object **to**, confess **to**, boast **about/of** |
| czasownik + **dopełnienie + przyimek + -ing** | accuse sb **of** · blame sb **for** · congratulate sb **on** · criticise sb **for** · forgive sb **for** · prevent/stop/deter/discourage sb **from** · suspect sb **of** · thank sb **for** · warn sb **against/about** · charge sb **with** · talk sb **into/out of** · dissuade sb **from** |
| czasownik + **that** + subjunctive/should | demand, insist, propose, recommend, suggest, request |

✗ *accused him **for*** · ✗ *suggested **me to*** · ✗ *apologised **to have done*** · ✗ *denied **to take*** · ✗ *explained **me*** → ✓ *explained **to me***

### 4.8 Inne struktury C2

- **be to + bezokol.** (formalne ustalenia/polecenia): *You **are to** report at 9.* / *The PM **is to** visit Kraków.*
- **be on the point/verge/brink of + -ing / rzeczownik**; **be about to**; **be due to**; **be set to**
- **only to + bezokol.** (rozczarowujący skutek): *He rushed to the station, **only to find** the train had gone.*
- **Konstrukcje absolutne:** ***It being** a holiday, the shops were closed.* / ***Weather permitting**, we'll go.*
- **„Wiszące” imiesłowy (błąd formalny):** ✗ *Walking home, the rain started.* ✓ *Walking home, **I** got caught in the rain.*

## MODUŁ 5 — ZDANIA ROZSZCZEPIONE (CLEFT SENTENCES) I EMFAZA

### 5.1 It-cleft

**Wzór:** `It + be + ELEMENT AKCENTOWANY + that/who + reszta zdania`

| Akcentowany element | Przykład |
|---|---|
| Podmiot (osoba) | *It was **John who/that** broke it.* |
| Dopełnienie | *It was **the vase that** he broke.* |
| Czas / miejsce / przyczyna | *It was **in 1066 that**…* / *It was **because he was ill that** he resigned.* |
| *not until* | *It was **not until 1928 that** women got equal voting rights.* |
| *only when* | *It was **only when** I saw her **that** I understood.* |
| *not X but Y* | *It is **not money but time that** I lack.* |

**Zasady:** po okolicznikach używaj **that** (✗ *It was in Paris **where** we met*). Formalna zgoda: *It is **I who am** responsible* (potocznie: *It's me who's*). Chcesz zaakcentować **czasownik**? → w it-cleft się nie da; użyj wh-cleft.

### 5.2 Wh-cleft (pseudo-cleft) i warianty

| Wzór | Przykład |
|---|---|
| What + zdanie + be + akcent | ***What I need is** a holiday.* |
| What + podmiot + did + was + (to) + bezokol. | ***What she did was (to) call** the police.* |
| What happened was (that) … | ***What happened was that** the bus broke down.* |
| All (that) + zdanie + be | ***All I did was ask** a question.* ✗ *All **what** I did* |
| The thing / The one thing / The only thing | ***The last thing I want is** an argument.* |
| The reason (why) … is **that** | ✗ *The reason is **because**…* |
| The person who / The place where / The day when | *Kraków is **the place where** I was born.* |
| Odwrócony | ***A holiday is what** I need.* / ***That's why**…* |

**Pułapki:** ✗ *What **does** irritate me is…* (brak *do* w zdaniach podmiotowych z *what*) · ✗ *All I did was **asked/asking*** · ✗ *All **what** I want* (kalka z polskiego *wszystko, co*).

### 5.3 Inne środki emfazy

- **Emfatyczne *do*:** *I **did** tell you!* / ***Do** sit down.* / *She **does** look tired.*
- **Wysunięcie na początek:** *That **I** can't accept.*
- **Wzmacniacze:** *no doubt **whatsoever** · not **in the least** · not **the slightest** idea · **the very** man · **by far** the best · **easily** the best · **much/far** better* · *What **on earth**…? · Why **ever**…?*
- **So/such:** *so + przymiotnik* · *such (a) + przymiotnik + rzeczownik* · *so much/many/few/little + rzeczownik* · *so much so that* · *to such an extent that* · ✗ *so good advice* → ✓ *such good advice*

### 6.4 Zwroty stałe — ucz się całymi blokami

| Para | Znaczenie |
|---|---|

### 6.5 Ludzie, tytuły, grupy

- Tytuł + imię: *King Charles, President Lincoln* (bez przedimka) vs ***the** King, **the** President, **the** Prince of Wales*.

- *the + przymiotnik* = grupa, czasownik w l. mnogiej: ***the** rich, **the** elderly, **the** homeless, **the** unemployed, **the** British, **the** Welsh, **the** Dutch, **the** Swiss, **the** Chinese*. **Rzeczowniki** narodowości mają -s: ***the** Poles, **the** Americans, **the** Scots, **the** Danes*.

- Statki/pociągi: ***the** Titanic, **the** Mayflower, **the** Flying Scotsman*.

### II.7 Skróty i rejestr (mechanika zadania A)

## V.2 UK — ustrój polityczny

- **Monarchia konstytucyjna, demokracja parlamentarna, niespisana (nieskodyfikowana) konstytucja** (ustawy, common law, konwencje konstytucyjne, dzieła autorytatywne).
- **Monarcha:** **King Charles III** (wstąpił na tron 8.09.2022, koronacja 6.05.2023, Opactwo Westminsterskie). Następca: **William, Prince of Wales** → George → Charlotte → Louis (ustawa z 2013 zniosła pierwszeństwo mężczyzn w sukcesji).
- **Parlament = Korona + Izba Gmin + Izba Lordów.**
  - **Izba Gmin (Commons):** **650 posłów (MPs)**, ordynacja większościowa (first-past-the-post) w okręgach jednomandatowych; obradom przewodniczy **Speaker**; PMQs (pytania do premiera) w środy.
  - **Izba Lordów:** niewybieralna — dożywotni parowie, 26 biskupów (Lords Spiritual) i malejąca liczba parów dziedzicznych (ustawa z 2024 r. ma ich usunąć — sprawdź aktualny status ⟳). Może **opóźnić**, ale nie zablokować większości ustaw (Parliament Acts **1911 i 1949**).
- **Rząd:** premier = lider partii mającej poparcie Izby Gmin; formalnie mianowany przez monarchę. Siedziba: **10 Downing Street**; kanclerz skarbu pod nr 11. *Whitehall* = administracja; *Westminster* = parlament.
- **Premier ⟳: Andy Burnham** (Labour) od **20 lipca 2026**, następca Keira Starmera (2024–26). Burnham to 7. premier od referendum w 2016 r.
- **Przywódcy regionów autonomicznych ⟳:** Szkocja — **John Swinney** (SNP) · Walia — **Rhun ap Iorwerth** (Plaid Cymru, od maja 2026 — pierwszy premier Walii spoza Partii Pracy) · Irlandia Płn. — First Minister **Michelle O'Neill** (Sinn Féin) i zastępczyni **Emma Little-Pengelly** (DUP).
- **Wybory:** co najwyżej co 5 lat (Dissolution and Calling of Parliament Act 2022). Czynne prawo wyborcze od 18 lat w wyborach do Westminsteru; od **16** w wyborach do parlamentów Szkocji i Walii.
- **Ceremoniał:** State Opening i **King's Speech** (mowa tronowa); przed **Black Rod** zatrzaskuje się drzwi Izby Gmin (pamiątka próby aresztowania pięciu posłów przez Karola I w 1642).
- **Partie:** Conservative (Tories), Labour, Liberal Democrats, Reform UK, Green, SNP, Plaid Cymru, DUP, Sinn Féin (nie obejmuje mandatów w Westminsterze), SDLP, Alliance.
- **Sądy:** **Supreme Court** od **2009** (zastąpił Law Lords). Szkocja ma własne **prawo szkockie** (system mieszany) i sądy; Anglia i Walia mają wspólny system; Irlandia Płn. odrębny. Ława przysięgłych: 12 osób w Anglii i Walii, **15** w szkockich sprawach karnych.
- **Kamienie milowe:** referendum brexitowe **23.06.2016** (51,9% za wyjściem) → wyjście z UE **31.01.2020**. Referendum niepodległościowe w Szkocji **2014** (55% przeciw). Dewolucja **1999**. Porozumienie wielkopiątkowe (Good Friday / Belfast Agreement) **10.04.1998**.

# CZĘŚĆ VI — KLUCZE ODPOWIEDZI

## KLUCZ A — Transformacje ze słowem kluczem

> Liczba słów obejmuje słowo klucz. ✓ = odpowiedź docelowa · (✓) = też akceptowalne · ✗ = dlaczego wersja „natywna” nie przechodzi.

**1.** **sooner had the minister finished** (5)
✗ *sooner **the minister had** finished* — brak inwersji · ✗ *…finished **when*** — *when* należy do *hardly/scarcely*; *no sooner* łączy się z **than** (już podanym). *No sooner did the minister finish* występuje w niektórych gramatykach, ale oczekiwany jest past perfect — nie ryzykuj.

**2.** **take our health for granted** (5)
✗ *take our health **as** granted* · ✗ *take our health granted* · *take for granted our health* — dopełnienie stoi **między** *take* a *for granted*, chyba że jest długie.

**3.** **wish I had taken** (4)
✗ *wish I **took*** (znaczenie teraźniejsze) · ✗ *wish I **would have** taken* (bardzo częste w mowie, niestandardowe) · ✗ *wish I **would take*** (*wish + would* dotyczy innych osób/rzeczy).

**4.** **are thought to have been** (5)
✗ ***is** thought…* — *there* uzgadnia się z *hundreds of people* · ✗ ***were** thought…* — czasownik relacjonujący w oryginale jest w teraźniejszym (*It is thought*) · ✗ *are thought **to be*** — uwięzienie było wcześniej.

**5.** **of his own accord** (4)
✗ ***on** his own accord* — klasyczny błąd natywny · ✗ *by his own accord* · ✗ *of his accord* (*own* jest obowiązkowe).

**6.** **had her flat broken into** (5)
✗ *had **broken into her flat*** — teraz to Sarah jest włamywaczką! · ✗ *had her flat **broken*** — *break into* = włamać się; partykuła **into** musi zostać.

**7.** **would rather you did not mention** (6)  (✓ *would rather you didn't mention* = 5, skrót liczy się jako jedno słowo)
✗ *would rather you **do not*** — inny podmiot wymaga **czasu przeszłego** · ✗ *would rather you **not** mention* — subjunctive amerykański, nie jest oczekiwany · ✗ *would rather **that** you did not mention* — 7 słów.

**8.** **did the fraud become apparent** (5)
✗ *the fraud became apparent* — *Only when…* wymusza inwersję w zdaniu głównym · ✗ ***became the fraud** apparent* — czasowniki leksykalne wymagają *did* · ✗ *did the fraud **became***.

**9.** **need not have booked** (4)  (✓ *needn't have booked*)
✗ *did not need to book* — nie mówi, że **zarezerwowaliśmy**, a oryginał tak mówi · ✗ *need not **to** have booked* · ✗ *did not need to **have** booked*.

**10.** **it not been for** (4)
✗ ***Hadn't** it been for* — inwersji warunkowej nigdy się nie skraca · ✗ *it been **not** for* · ✗ *not it been for*.

**11.** **is at odds with** (4)
✗ *is **in** odds with* · ✗ *is at **odd** with* · ✗ *is at odds **to***.

**12.** **All I did was ask** (5)  (✓ *All I did was to ask* = 6)
✗ *All **what** I did* — kalka z *wszystko, co*; poprawnie *all (that)* · ✗ *was **asked*** / *was **asking*** — po *All/What … did was* stoi bezokolicznik (bez *to* lub z *to*).

**13.** **occurred to me to check** (5)
✗ *occurred **me*** — *occur **to** sb* · ✗ *occurred to me **checking*** · ✗ *occurred to me that I should check* — 7 słów.

**14.** **Little did Kate know** (4)  (✓ *realise / suspect / imagine*)
✗ *Little **Kate knew*** — brak inwersji · ✗ *Little did Kate **knew*** · Użyj **Kate**, nie *she*: imię nie pojawia się nigdzie indziej w nowym zdaniu.

**15.** **could not possibly have written** (5)  (✓ *cannot possibly have written* = 4)
✗ ***must not** have written* — dedukcja amerykańska; w kluczach brytyjskich *must not* = zakaz · ✗ *cannot possibly have **wrote*** — dialektalny imiesłów.

**16.** **suggested that the meeting be** (5)  (✓ *suggested (that) the meeting should be* · ✓ *suggested the meeting be*)
✗ *suggested the meeting **to be*** — *suggest* nigdy nie łączy się z dopełnieniem + *to* · ✗ *suggested that the meeting **was*** — teraz znaczy, że *twierdził*, iż spotkanie przełożono · ✗ *…**is** postponed* — potoczny tryb oznajmujący, zły czas.

**17.** **were kept in the dark about** (6)  (✓ *were left in the dark about*)
✗ *were kept in **dark*** — potrzebny przedimek · ✗ *in the dark **of*** · ✗ *in the darkness*.

**18.** **Try as he might** (4)  (✓ *Try as he may*)
✗ *As he might try* · ✗ *Trying as he might* · ✗ *Try **as hard as** he might* — zlepek dwóch konstrukcji; unikaj.

**19.** **high time you started** (4)  (✓ *high time for you to start* = 6)
✗ *high time you **start*** · ✗ *high time you **should** start* · ✗ *high time you **had started***.

**20.** **bore the brunt of** (4)  (✓ *took the brunt of*)
✗ ***beared** the brunt* — czas przeszły od *bear* to **bore** · ✗ *the **brunts** of*.

**21.** **no time were the prisoners informed** (6)
✗ *no time **the prisoners were*** — brak inwersji · ✗ ***In** no time…* — znaczy „bardzo szybko” i nigdy nie wywołuje inwersji · ✗ *no time had the prisoners been informed* — 7 słów i zmiana czasu.

**22.** **accused Mr Hale of leaking** (5)  (✓ *accused Mr Hale of having leaked* = 6)
✗ *accused Mr Hale **for** leaking* (*blame sb **for***, *accuse sb **of***) · ✗ *accused Mr Hale **to have** leaked* · ✗ *accused Mr Hale **that** he leaked* · Użyj nazwiska: *him* nie miałoby do czego się odnosić.

**23.** **Had I accepted the job** (5)  (✓ *If I had accepted the job* = 6)
Okres mieszany: warunek w przeszłości → skutek teraz (*would not still be living*).
✗ *If I **would have** accepted* · ✗ *If I **accepted*** — 2. tryb = zły czas.

**24.** **was not until the 1940s** (5)  (✓ *wasn't until the 1940s*)
✗ *was **only** until* · ✗ *was not **before*** · ✗ *not until **1940s*** — dekady wymagają *the*.

**25.** **turned a blind eye to** (5)
✗ *turned a blind eye **on*** · ✗ ***closed** a blind eye* · ✗ *turned **blind eye***.

**26.** **Were the government to raise** (5)
✗ ***Was** the government to raise* — inwersję tworzy tylko *were* · ✗ *Were the government **raise*** — potrzebne *to* · ✗ *Should the government raise* — dobry pomysł, ale nie używa **WERE**.

**27.** **me none the wiser** (4)
✗ *me none **wiser*** · ✗ *me none the **wise*** · ✗ *me **not** the wiser*.

**28.** **in the face of strong** (5)
✗ ***on** the face of* — *on the face of it* = „na pierwszy rzut oka”, inny idiom · ✗ *in face of* — mniej standardowe; pisz *in the face of*.

**29.** **was on the brink of** (5)  (✓ *was teetering on the brink of* = 6 · *was on the verge of* — poprawne, ale nie używa BRINK)
✗ *on the brink **to*** · ✗ *on **a** brink of* · ✗ ***at** the brink of*.

**30.** **fell short of our** (4)
✗ ***felt** short of* — *fall–fell–fallen* vs *feel–felt* · ✗ *fell short **from*** · ✗ *were short of our* — znaczy „brakowało”, inne znaczenie.
