# CZĘŚĆ I — MODUŁY GRAMATYCZNE

## 1. Inwersja (operator PRZED podmiotem)

| Wyzwalacz | Wzór |
|---|---|
| Never / Rarely / Seldom / Little | **Never have I** seen… · **Little did he** know… (po *did* forma podstawowa) |
| No sooner … **than** | **No sooner had he left than** it rained |
| Hardly / Scarcely / Barely … **when** (*before*) | **Hardly had we sat down when**… |
| Not only … but also | **Not only did he lie, but he also** forged… (inwersja tylko w 1. części) |
| Not until / Only when / Only after / Only then | Not until I saw it **did I realise**… (odwracasz zdanie **główne**) |
| At no time / On no account / Under no circumstances / In no way / By no means | **On no account** (l. poj.) · **Under no circumstances** (l. mn.) + *must/should/will you…* |
| Nowhere / Not once / Not a word / No longer / Not since | **Nowhere else will you** find… · **Not once did she**… · **Not a word did he** say |
| So + przym. … that / Such + be … that | **So violent was** the storm that… · **Such was** the demand that… |
| Nor / Neither / So | …, **nor can** her brother · …, **so has** she |

**Bez inwersji:** słowo przeczące w podmiocie (*Hardly anyone came*, *Not many people know*, *Only Tom knew*) · *in no time* (= szybko) · wyrażenie nie na początku (*I have never seen*). Czasownik leksykalny bez operatora → dodaj *do/does/did*.

**Inwersja zamiast *if*** (tylko **had / were / should**; przeczenie zawsze pełne, nigdy z *if*):
**Should you need** help… · **Were he to resign**… · **Were I** rich… · **Had I known**… · **Had it not been for** you… ✗ *Hadn't it been*, ✗ *Was I to*, ✗ *If should you*.

**Inwersja przyzwalająca:** **Tired as I was**, I kept working · **Much as I admire** her… · **Try as he might**… · **Child though he was** (bez przedimka) · **Strange as it may seem** · However hard he tried (✗ *However he tried hard*). ✗ *As tired as I was* w kluczu preskryptywnym.

**Inwersja miejscowa:** **Into the room burst** a policeman · **Here comes** the bus (ale *Here it comes* — zaimek bez inwersji) · **Gone are the days** when… · "Stop!" **said the officer**.

**Szyk:** *too difficult **a** task*, *as good **a** player as*, *how big **a** problem* (✗ *too difficult **of** a task*).

## 2. Okresy warunkowe, unreal past, subjunctive

| Typ | if | główne |
|---|---|---|
| 2. | past simple / **were** | would + inf |
| 3. | past perfect | would **have** + III |
| mieszany A | past perfect | would + inf (**teraz**) — *If I had accepted the offer, I would be living in Dublin now* |
| mieszany B | past simple / were | would have + III — *If she weren't so shy, she would have spoken up* |

✗ *If I would have known* → *If I had known*. *Will/would* po *if* tylko jako uprzejmość lub upór (*If you would wait here…*).
**Zamienniki *if*:** unless (= if … not; ✗ *unless you don't*) · provided/providing (that), as long as, on condition that · **in case** (środek ostrożności, nie warunek) · in the event of · suppose / what if + past · **but for** + rzeczownik · otherwise / or else · only if (+ inwersja w głównym) · given that · if need be / if so / if not.

**Wish / If only:** teraźniejszość → *wish + past / **were*** (✗ *I wish I was*) · umiejętność → *could* · żal o przeszłość → **past perfect** (✗ *wish I would have*) · irytacja (ktoś/coś innego) → *wish + would* · formalne → *I wish to complain*.
**Would rather / had better / prefer:** ten sam podmiot → inf bez *to* (*I'd rather stay*) · inny podmiot → **past simple** (*I'd rather you **didn't***) lub **past perfect** o przeszłości (*I'd rather you **hadn't told** her*) · *had better (not)* + inf bez *to* · *prefer walking **to** cycling* / *prefer to walk **rather than** cycle* · *I'd prefer **it if** you left*.
**It's (high/about) time** + **past simple**: *It's high time we **left*** (✗ *leave / should leave*) lub *time **for us to** leave*.
**As if / as though:** realne → normalny czas; nierealne → past / **were** (*as if he **were** the boss*). ✗ *looks like it will rain* w zadaniach formalnych.
**Subjunctive nakazowy:** *advise, ask, demand, insist, order, propose, recommend, request, require, suggest, urge* / *essential, imperative, vital, crucial, important, necessary* + **that** + podmiot + **inf bez *to*** (bez *-s*; przeczenie *not be*): *She suggested that the meeting **be** postponed.* · alternatywa brytyjska *should be*. ✗ *suggest him to go*, ✗ *suggested to postpone*, ✗ *insisted that she leaves*. Uwaga: *He insisted that he **was** innocent* = twierdził (nie żądał).
**Skamieniałe:** God save the King · Be that as it may · Come what may · Suffice it to say · So be it · Far be it from me · If need be · Heaven forbid · Truth be told.

## 3. Czasowniki modalne w przeszłości

| Forma | Znaczenie |
|---|---|
| **must have** + III | na pewno tak |
| **can't / couldn't have** + III | na pewno nie (✗ *mustn't have*) |
| **may / might / could have** + III | możliwe; *might/could have* też „mogło się zdarzyć, ale nie” (✗ *may* w kontrfaktach) |
| **should / ought to have** + III | trzeba było (nie zrobiono) · *shouldn't have* = nie trzeba było (zrobiono) |
| **needn't have** + III | zrobiono niepotrzebnie · *didn't need to* + inf = nie było potrzeby (zwykle nie zrobiono) |
| **was supposed to** / **was to have** + III | plan, który nie wyszedł |
| **might as well have** / **may well have** | i tak bez różnicy / całkiem możliwe |
| **would rather have** + III | preferencja w przeszłości |
| **wouldn't** + inf | odmowa (*The door wouldn't open*) |

✗ *could of* → *have* · ✗ *should have went* → *gone* · ✗ *needn't have to* · jednorazowy sukces w przeszłości: *managed to / was able to*, nie *could* (*couldn't* i zmysły są OK).
C2: *should* „przypuszczające” (*It's odd that he **should** say that*) · *Need I remind you…?* · *How dare you* · *I dare say* · *He would say that, wouldn't he?* · bierna: *must have been stolen*.

## 4. Struktury złożone i wzorce czasownikowe

**Complex subject (transformacja nr 1):**
- *It is believed that he left* → **He is believed to have left** (wcześniej) · *…that he is hiding* → *He is believed **to be** hiding* (równocześnie).
- Bierna: *The money is believed **to have been stolen***. *There* uzgadnia się z rzeczywistym podmiotem: ***There are** thought **to have been** hundreds…*
- Czasownik relacjonujący zachowuje czas oryginału (*believes* → *is believed*, *believed* → *was believed*). Przyszłość: *He is **expected to win***.
- Czasowniki: say, believe, think, know, consider, report, expect, allege, assume, estimate, presume, suppose, understand. Podobnie *seem, appear, happen, turn out, prove, tend, be likely/bound/certain to* (*He turned out to have lied*).

**Dopełnienie:** w stronie biernej wraca *to*: *made him wait* → *He was made **to** wait*; *saw her enter* → *She was seen **to** enter*. *Let* → *was allowed to*. ✓ *I'd appreciate **it** if* · *I find **it** hard to* · *She made **it** clear that*. *allow/permit/forbid/advise* + **-ing** bez dopełnienia, **to** + inf z dopełnieniem.

**Kauzatyw:** **have + dopełnienie + III** (usługa lub nieszczęście: *had her flat broken **into*** — partykuła zostaje!) · **get sth done** · **have sb do** · **get sb to do** · **make sb do** · **have sb -ing** · **need + -ing** (*needs washing*).

**Gerund vs bezokolicznik (zmiana znaczenia):** *remember/forget* -ing = przeszłość, to = obowiązek · *regret* -ing = żałować, *regret to inform* · *try* -ing = eksperyment, to = starać się · *stop* -ing = przestać, to = zatrzymać się, by · *go on* · *mean* · *propose*.
**To + -ing (pułapka przyimkowa):** look forward to, object to, be/get used to, be committed to, in addition to, with a view to, when it comes to, resort to, prior to. ✗ *look forward to hear*.

**Czasowniki relacjonujące:**
- + **to** inf: agree, offer, refuse, promise, threaten, claim, pretend, decline.
- + dopełnienie + **to** inf: advise, urge, persuade, remind, warn, encourage, beg, invite, order, forbid.
- + **-ing** / *having* + III: deny, admit (to), suggest, recommend, regret, mention.
- + przyimek + -ing: apologise **for**, insist **on**, object **to**, confess **to**, boast **about**.
- + dopełnienie + przyimek + -ing: accuse sb **of** · blame sb **for** · congratulate sb **on** · criticise/forgive/thank sb **for** · prevent/stop/discourage sb **from** · suspect sb **of** · warn sb **against** · charge sb **with** · talk sb **into/out of**.
- ✗ *accused him for*, ✗ *suggested me to*, ✗ *explained me* → *explained **to me***.

**Inne:** **be to** (*You are to report at 9*) · **only to** (*rushed to the station, only to find…*) · konstrukcje absolutne (*It being a holiday…*, *Weather permitting…*) · **wiszący imiesłów**: ✗ *Walking home, the rain started* ✓ *Walking home, **I** got wet*.

## 5. Cleft i emfaza

- **It-cleft:** *It was **John who/that** broke it* · *It was **in 1066 that**…* · *It was **not until 1928 that**…* · *It was **only when** I saw her **that** I understood* · po okolicznikach **that** (✗ *where*).

## III.C Gramatykalizacja i „wisielec” (zadanie C)

- **Gramatykalizacja:** zachowaj kolejność podanych wyrazów → zmień formę (czas, strona, gerund) → dodaj brakujące słowa gramatyczne (operatory, przedimki, przyimki, *not*) → sprawdź wskazówki (*for three years* → perfect, *by the time* → past perfect, *Not until* → inwersja).

# LISTA KONTROLNA — wieczór przed testem

- [ ] Inwersja: *No sooner… **than*** · *Hardly… **when*** · po *Only when / Not until* odwracaj zdanie **główne**
- [ ] Inwersji warunkowej nie skracamy: *Had it **not** been for*
- [ ] *would rather / it's high time* + **czas przeszły** · *wish* + past perfect dla żalu
- [ ] *suggest / insist / essential that* + **bezokolicznik bez to**
- [ ] *needn't have done* (zrobiono) vs *didn't need to do*
- [ ] Complex subject: czas czasownika relacjonującego bez zmian; bezokolicznik pokazuje, co było wcześniej; *there* zgadza się z rzeczywistym podmiotem
- [ ] Kauzatyw: zachowaj partykułę (*had her flat broken **into***)
- [ ] *of one's own accord* · *bore the brunt* · *fell short of*
- [ ] Pisownia: sprawdź każdą odpowiedź literka po literce
- [ ] ≤ 6 słów ze słowem kluczem · słowo klucza bez zmian · skrót = 1 wyraz
- [ ] Kultura: premier **Andy Burnham**, król **Karol III**, prezydent **Trump** (47.) — sprawdź ponownie
- [ ] **19.10.2026, 14:00** · 45 pytań w 45 minut · nie zatrzymuj się, nie zostawiaj pustych pól
