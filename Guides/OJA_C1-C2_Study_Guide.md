## MODULE 1 — INVERSION

**Inversion = auxiliary BEFORE subject** (question word order) in a statement, triggered by a fronted negative/restrictive element, a conditional, or a stylistic choice.

### 1.1 Negative & restrictive adverbials

**Formula:** `Negative adverbial + AUXILIARY + SUBJECT + main verb`
No auxiliary in the original? Add **do/does/did** (and use the **bare infinitive** after it).

| Trigger | Model sentence | Watch out |
|---|---|---|
| Never (before) | **Never have I seen** such chaos. | |
| Rarely / Seldom (, if ever,) | **Seldom, if ever, does she** complain. | |
| Little | **Little did they know** what awaited them. | always *did + know/realise/suspect* |
| Hardly / Scarcely / Barely … **when/before** | **Hardly had we sat down when** the phone rang. | past perfect + **when** (never *than*) |
| No sooner … **than** | **No sooner had he left than** it started to pour. | past perfect + **than** (never *when*) |
| Not only … but (also) | **Not only did he lie, but he also** forged documents. | inversion in **first** clause only |
| Not until + time/clause | **Not until 2005 did** the truth emerge. | inversion in the **main** clause |
| Only + adverbial | **Only then / later / recently / in this way / by doing X** did/can… | |
| Only when / after / if + clause | **Only when the results arrived did we** celebrate. | inversion in the **main** clause |
| At no time | **At no time were** the prisoners told. | ≠ *in no time* (= very quickly, **no** inversion) |
| On no account | **On no account must you** open it. | singular *account* |
| Under no circumstances | **Under no circumstances should** you sign. | plural *circumstances* |
| In no way / By no means / In no sense | **In no way is this** acceptable. | |
| Nowhere (else) | **Nowhere else will you find** such views. | |
| Not once / Not for a moment | **Not once did she** look back. | |
| Not a + noun (fronted object) | **Not a word did he say.** | |
| No longer | **No longer do we** accept cash. | |
| Not since | **Not since the 1960s has the party** won so many seats. | |
| So + adj/adv … that | **So violent was the storm that** flights were cancelled. | |
| Such + be … that | **Such was the demand that** the site crashed. | *such* + *be* + NP |
| Neither / Nor | She can't swim, **nor can her brother**. | |

**When NOT to invert**

| Situation | Correct (no inversion) |
|---|---|
| The negative word belongs to the **subject** | **Hardly anyone** came. / **Not many people** know. / **Only Tom** knew. |
| *In no time* (= quickly) | We were home **in no time**. |
| *Not long ago* (not negative in meaning) | **Not long ago** I met her. |
| Adverbial not fronted | I have **never** seen such chaos. / He **not only** lied **but also**… |
| Fixed phrase *Not only that,* | **Not only that, but** he was late too. |

**Native pitfalls**

| ✗ Sounds natural | ✓ Exam answer | Why |
|---|---|---|
| No sooner had I arrived **when** she left. | …**than** she left. | correlative is fixed |
| Hardly had I arrived **than**… | …**when/before**… | |
| Only when he left **I realised**. | …**did I realise**. | inversion in the main clause |
| Not until **did I see** the news I realised. | Not until I saw the news **did I realise**. | wrong clause inverted |
| Little **did I knew**. | Little did I **know**. | bare infinitive after *did* |
| Never **I have** seen… | Never **have I** seen… | |
| **Became the fraud** apparent. | **Did the fraud become** apparent. | lexical verbs need *do*-support |
| Under no **circumstance**… | Under no **circumstances**… | fixed plural |
| On **any** account… | On **no** account… | |

### 1.2 Conditional inversion (drop *if*)

| Type | With *if* | Inverted | Negative inverted |
|---|---|---|---|
| 1st (unlikely future) | If you **should** need help… | **Should you need** help… | **Should you not** wish to… |
| 2nd | If I **were** rich… / If he **were to** resign… | **Were I** rich… / **Were he to resign**… | **Were it not for** your help… |
| 3rd | If I **had** known… | **Had I known**… | **Had it not been for** you… |
| Mixed (past → present) | If I had taken the job, I'd be in Paris now. | **Had I taken** the job, I would be in Paris now. | |
| Mixed (present → past) | If I weren't so busy, I'd have come. | **Were I not** so busy, I would have come. | |

**Iron rules**

1. Only **had / were / should** invert. ✗ *Was I to…* ✗ *Would I…*
2. **Never** contract an inverted negative: ✗ *Hadn't it been for…* ✓ *Had it not been for…*
3. **Never** combine *if* + inversion: ✗ *If should you need…*
4. *Were* + **to**-infinitive for hypothetical actions: ✓ *Were the government **to raise** taxes…*

### 1.3 Concessive inversion ("fronted adjective + as/though")

**Formula:** `Adjective / Adverb / (bare) Noun + as/though + subject + verb`

| Model | Notes |
|---|---|
| **Tired as I was**, I kept working. | = Although I was tired |
| **Hard though she tried**, she failed. | |
| **Much as I admire** her, I disagree. | very common in KWT |
| **Try as he might**, he couldn't open it. | fixed: *Try as + subj + might/may* |
| **Child though he was**, he understood. | **no article** with the noun |
| **Strange as it may seem**, it's true. | |
| **However hard** he tries, … / **No matter how** hard… | not inversion, but same meaning |
| **For all** his wealth, he was lonely. | = despite |
| **Be that as it may**, … / **Come what may**, … | frozen subjunctive |

**Native pitfalls**

- ✗ *As tired as I was, I kept working.* — common in speech (esp. AmE) but risky in a prescriptive key. Use **Tired as I was**.
- ✗ *As he was young, he understood* — *as* here means **because**: meaning changes.
- ✗ *A child as he was…* — drop the article.
- ✗ *However he tried hard* → ✓ *However hard he tried*.

### 1.4 Stylistic & locative inversion (full verb before subject)

| Pattern | Example | Restriction |
|---|---|---|
| Place/direction adverbial + intransitive verb | **Into the room burst** a policeman. / **On the hill stood** a castle. | **noun** subjects only: *Off **they** went* (no inversion with pronoun) |
| *Here/There* + come/go | **Here comes** the bus. / **Here it comes.** | pronoun → no inversion |
| Fronted participle/adjective + *be* | **Gone are the days** when… / **Attached is** my CV. / **Especially worrying is** the cost. | formal |
| Reporting verb after direct speech | "Stop!" **said the officer.** | ✗ *said he* (archaic) |
| Comparisons (formal, optional) | She earns more **than does** her husband. / …**as did** his father. | not with pronoun subjects |
| *So / Neither / Nor* tags | I've finished, and **so has she**. | *So it is!* = surprised agreement (no inversion) |

### 1.5 Bonus: the "so/too/as/how + adjective + a + noun" order

✓ *It was **too difficult a task**.* ✓ *She's **as good a player as** her sister.* ✓ ***So beautiful a city**…* ✓ ***How big a problem** is it?*
✗ *too difficult **of** a task* (AmE informal) ✗ *a too difficult task*

## MODULE 2 — CONDITIONALS, UNREAL PAST & SUBJUNCTIVE

### 2.1 The full conditional map

| Type | If-clause | Main clause | Use |
|---|---|---|---|
| Zero | present | present | general truths |
| 1st | present | will / modal + inf | real future |
| 2nd | past simple / **were** | would/could/might + inf | unreal present/future |
| 3rd | past perfect | would/could/might **have + pp** | unreal past |
| Mixed A | past perfect | would + inf (**now**) | past cause → present result |
| Mixed B | past simple / were | would **have + pp** | permanent state → past result |

> **Mixed A:** *If I **had accepted** the offer, I **would be living** in Dublin now.*
> **Mixed B:** *If she **weren't** so shy, she **would have spoken** up yesterday.*

### 2.2 *Will/would* inside the if-clause — when it's legal

| Legal use | Example |
|---|---|
| Politeness | *If you **will/would** wait here, I'll fetch the manager.* |
| Insistence / annoying habit (stressed) | *If you **will** keep eating junk, you'll get ill.* |
| The result is the reason for the action | *If it **will** help, I'll lend you the money.* |
| ✗ Native error | ✗ *If I **would have** known…* → ✓ *If I **had** known…* |

### 2.3 Alternatives to *if*

| Expression | Meaning / pattern |
|---|---|
| unless | = if … not (✗ *unless you don't*) |
| provided / providing (that), as/so long as, on condition that | strong condition |
| in case | **precaution, not condition**: *Take an umbrella **in case** it rains* ≠ *if it rains* |
| in the event of + NP / in the event that + clause | formal |
| suppose / supposing / what if / imagine | + past for unreal |
| but for + NP | = if it were not / had not been for |
| otherwise / or else | *Hurry, **otherwise** we'll miss it.* |
| even if / only if | *Only if* + inversion in main clause |
| given (that), assuming (that) | |
| if need be, if in doubt, if so, if not, if anything | fixed |

### 2.4 Wish / If only

| Time | Form | Example |
|---|---|---|
| Present state | wish + past simple / **were** | *I wish I **were** taller.* |
| Present ability | wish + **could** | *I wish I **could** drive.* |
| Past regret | wish + **past perfect** / could have + pp | *I wish I **had listened**.* |
| Annoyance / desire for change (**someone or something else**) | wish + **would** + inf | *I wish you **would** stop.* / *I wish it **would** rain.* |
| Formal "want" | wish + **to**-inf | *I wish **to** complain.* |

**Native pitfalls:** ✗ *I wish I would have…* · ✗ *I wish I would stop* (use *could*) · ✗ *I wish I was* (informal → **were** in tests) · ✗ *I wish she would be taller* (states don't take *would*).

### 2.5 Would rather / would sooner / had better / prefer

| Pattern | Example |
|---|---|
| Same subject → **bare infinitive** | *I'd rather **stay**.* / *I'd rather **not** say.* |
| Different subject → **past simple** (present/future meaning) | *I'd rather you **didn't** smoke here.* |
| Different subject → **past perfect** (past meaning) | *I'd rather you **hadn't told** her.* |
| would rather X **than** Y (both bare) | *I'd rather walk **than** take the bus.* |
| had better + bare inf | *You **had better not** be late.* ✗ *had better **to*** |
| prefer **-ing to -ing** | *I prefer walking **to** cycling.* |
| prefer **to**-inf **rather than** bare inf | *I prefer to walk **rather than** cycle.* |
| would prefer sb **to** do / would prefer **it if** sb **did** | *I'd prefer **it if** you **left**.* |

✗ *I'd rather you **don't*** · ✗ *I'd rather you **to** leave* · AmE *I'd rather you **not** go* is a subjunctive variant — **not** the expected exam answer.

### 2.6 It's time / It's high time / It's about time

- ✓ *It's (high/about) time **we left**.* (past simple, present meaning — implies "it's late")
- ✓ *It's time **for us to leave**.* / *It's time **to leave**.*
- ✗ *It's high time we **leave**.* ✗ *…we **should** leave.* ✗ *…we **had left**.*

### 2.7 As if / as though

- Real possibility → normal tense: *It looks **as if** it**'s going to** rain.*
- Unreal → past / **were**: *He talks **as if** he **owned** the place.* / *…as if he **were** the boss.*
- ✗ *It looks **like** it's going to rain* (informal — use *as if* in formal tasks).

### 2.8 The mandative subjunctive (KWT favourite)

**Formula:** `verb / adjective / noun of demand + that + subject + BARE INFINITIVE` (no -s, no tense shift, negative = *not* + base)

| Triggers | Example |
|---|---|
| **Verbs:** advise, ask, beg, demand, insist, order, propose, recommend, request, require, stipulate, **suggest**, urge | *She **suggested that** the meeting **be postponed**.* |
| **Adjectives:** essential, imperative, vital, crucial, important, necessary, advisable, desirable | *It is **essential that** he **be** informed.* |
| **Nouns:** demand, proposal, recommendation, requirement, insistence | *the **requirement that** every candidate **sign** in* |
| Negative | *We recommend **that** the plan **not be** adopted.* |
| BrE alternative | *…that the meeting **should be** postponed.* ✓ |

**Native pitfalls:** ✗ *suggest **him to** go* · ✗ *suggested **to** postpone* · ✗ *insisted that she **leaves*** (informal BrE; in tests use **leave / should leave**).
**Meaning trap:** *He insisted that he **was** innocent* = he claimed (indicative) ≠ *He insisted that she **be** present* = he demanded.

**Frozen subjunctives to recognise:** *God save the King · Long live… · Be that as it may · Come what may · Suffice it to say · So be it · Far be it from me to… · If need be · Heaven forbid · As it were · Truth be told · Woe betide…*

## MODULE 3 — MODAL VERBS IN THE PAST

### 3.1 Master table

| Form | Function | Example |
|---|---|---|
| **must have + pp** | certain YES (deduction) | *She **must have left** — her coat's gone.* |
| **can't / couldn't have + pp** | certain NO | *He **can't have written** this — he can't spell.* |
| **may / might / could have + pp** | possible | *They **might have missed** the bus.* |
| **might / could have + pp** (counterfactual) | it was possible but didn't happen | *You **could have been** killed!* |
| **should / ought to have + pp** | criticism, regret (not done) | *You **should have told** me.* |
| **shouldn't / ought not to have + pp** | criticism (was done) | *I **shouldn't have eaten** that.* |
| **should have + pp** (expectation) | expected by now | *They **should have arrived** by now.* |
| **needn't have + pp** | **was done**, but unnecessary | *We **needn't have booked** — it was empty.* |
| **didn't need to + inf** | unnecessary (usually **not done**) | *We **didn't need to book**, so we didn't.* |
| **didn't have to + inf** | no obligation | *I **didn't have to** wear a uniform.* |
| **would have + pp** | unreal past result | *I **would have helped**.* |
| **wouldn't + inf** (past) | refusal | *The door **wouldn't open**.* |
| **will have + pp** | confident assumption about the past | *You **will have heard** the news.* |
| **was/were supposed to + inf** | planned/expected, didn't happen | *I **was supposed to** call her.* |
| **was/were to have + pp** | formal unrealised plan | *The ceremony **was to have taken** place in May.* |
| **might as well have + pp** | it would have made no difference | *We **might as well have stayed** at home.* |
| **may/might well have + pp** | it's quite likely that | *She **may well have forgotten**.* |
| **would rather have + pp** | past preference | *I'd **rather have gone** to the cinema.* |

### 3.2 Native pitfalls

| ✗ | ✓ | Rule |
|---|---|---|
| He **mustn't have** heard. | He **can't/couldn't have** heard. | *mustn't* = prohibition in BrE; *must not have* is AmE |
| You **needn't have to** come. | You **needn't have come** / **didn't need to come**. | never *needn't have to* |
| We **didn't need to have** booked. | We **needn't have booked**. | |
| I **could of** gone. | I **could have** gone. | spelling of the weak form /əv/ |
| You **should have went**. | You **should have gone**. | past participle (dialect error!) |
| After hours, we **could find** the key. | …we **managed to / were able to** find it. | single past achievement ≠ *could* (negatives and senses are fine: *couldn't find*, *could see*) |
| The patient **may have** survived if the ambulance had come. (he died) | …**might have** survived… | counterfactual = *might/could*, not *may* |
| **Can** have he forgotten? | **Could** he have forgotten? | |

### 3.3 Other modal C2 points

- **Putative *should*:** *It's odd that he **should** say that.* / *Who **should** walk in but my ex!*
- **Modal *need*** (BrE formal, negatives/questions only, no *-s*, bare inf): ***Need** I remind you…?* / *He **needn't** come.*
- **Dare:** *How **dare** you!* / *I **dare say*** (= I suppose) / *She **daren't** tell him.*
- ***Shall*** in legal texts: *The tenant **shall** pay…*
- ***Would*** for typical (annoying) behaviour: *He **would** say that, wouldn't he?*
- **Passive modal perfect:** *must have been stolen · should have been told · can't have been seen*

## MODULE 4 — COMPLEX STRUCTURES & VERB PATTERNS

### 4.1 The infinitive & gerund grid

| | Active | Passive |
|---|---|---|
| Simple infinitive | to do | to be done |
| Continuous infinitive | to be doing | (to be being done — avoid) |
| Perfect infinitive | to have done | to have been done |
| Perfect continuous infinitive | to have been doing | — |
| Gerund | doing | being done |
| Perfect gerund | having done | having been done |

### 4.2 Complex subject (passive reporting) — the #1 transformation

**Two patterns:**
- `It + is/was + said/believed/thought… + that + clause`
- `Subject + is/was + said/believed/thought… + TO-INFINITIVE`

**Verbs:** say, believe, think, know, consider, report, expect, allege, assume, estimate, presume, rumour (passive only), suppose, understand, fear, acknowledge.

**Time mapping (reporting verb in present: "People believe…")**

| Original clause | Complex subject |
|---|---|
| …that he **is** hiding. | He is believed **to be hiding**. |
| …that he **lives** abroad. | He is believed **to live** abroad. |
| …that he **left / has left / had left**. | He is believed **to have left**. |
| …that he **has been working**… | He is believed **to have been working**… |
| …that the money **was stolen**. | The money is believed **to have been stolen**. |
| …that he **will win**. | He is **expected to win**. / It is thought that he will win. |
| …that there **were** survivors. | There are believed **to have been** survivors. |

> **Golden rule:** the passive reporting verb keeps the **original reporting tense** (*believe* → *is believed*; *believed* → *was believed*); the infinitive shows whether the reported event is **simultaneous** (*to be*) or **earlier** (*to have been*).
> **There-trap:** *there* agrees with the **real** subject: *There **are** thought to have been **hundreds** of people…*

**Raising verbs** (same logic): *seem, appear, happen, turn out, prove, tend* + *to*-inf; *be likely/unlikely/certain/sure/bound/due/set/about* + *to*-inf.
*It turned out that he had lied* → *He **turned out to have lied**.* · *It happened that I was there* → *I **happened to be** there.*

### 4.3 Complex object & the "to reappears in the passive" rule

| Active | Passive | Note |
|---|---|---|
| They **made** him **wait**. | He **was made to wait**. | *to* reappears |
| I **saw** her **enter**. | She **was seen to enter**. / **seen entering** | *to* reappears |
| They **let** him **go**. | He **was allowed to go**. | *let* has no normal passive (idioms: *be let go*, *be let off*) |
| They **helped** us (**to**) move. | We **were helped to move**. | |
| I **want** you **to** go. / I'd **like** it **to** be done. | — | ✗ *I want that you go* |
| I **consider** him (**to be**) the best. | He **is considered** (**to be**) the best. | formal |
| They **allow** us **to** smoke. / They **allow smoking**. | We **are allowed to** smoke. / Smoking **is allowed**. | *allow/permit/forbid/advise/recommend* + **-ing** without object, **to-inf** with object |

**Dummy *it* as object (native error zone):** ✓ *I'd appreciate **it** if you could…* ✗ *I'd appreciate if you could…* · ✓ *I take **it** that…* · ✓ *I hate **it** when…* · ✓ *She made **it** clear that…* · ✓ *I find **it** hard to believe…*

### 4.4 Causatives

| Structure | Meaning | Example |
|---|---|---|
| **have** + object + **pp** | arrange a service | *I **had my hair cut**.* |
| **have** + object + **pp** | something bad happened to you | *She **had her flat broken into**.* (keep the particle!) |
| **get** + object + **pp** | arrange / manage to complete | *I need to **get this report finished**.* |
| **have** + person + **bare inf** | instruct (authority) | *I'll **have my assistant call** you.* |
| **get** + person + **to**-inf | persuade | *I **got him to lower** the price.* |
| **make** + person + **bare inf** | force | *She **made me apologise**.* |
| **have** + person + **-ing** | cause an ongoing effect | *He **had us laughing** all night.* / *I **won't have you speaking** like that.* |
| **get** + object + **-ing** | start sth working | *I **got the engine running**.* |
| **need/want + -ing** | passive meaning | *The car **needs washing** / **needs to be washed**.* |
| make oneself + pp | | *make oneself **understood / heard*** |

### 4.5 Gerund vs infinitive — meaning changes

| Verb | + -ing | + to-inf |
|---|---|---|
| remember / forget | memory of a past act | duty not to forget |
| regret | sorry about the past | *We regret **to inform** you* (formal announcement) |
| try | experiment | make an effort |
| stop | quit the activity | stop in order to |
| go on | continue the same thing | move on to a new thing |
| mean | involve | intend |
| need | passive sense (*needs fixing*) | necessity |
| propose | suggest | intend |
| be afraid | fear of what might happen | too scared to act |

### 4.6 *To* + -ING (the preposition trap)

`look forward to · object to · be/get used to · be accustomed to · be committed to · be devoted/dedicated to · be opposed to · admit to · confess to · in addition to · with a view to · when it comes to · take to · resort to · prior to · the key to · come close to`

✗ *I look forward to **hear*** · ✗ *He's used to **work** late* · ✗ *with a view to **buy***

### 4.7 Reporting verb patterns (KWT staple)

| Pattern | Verbs |
|---|---|
| verb + **to**-inf | agree, offer, refuse, promise, threaten, claim, pretend, decline, vow |
| verb + **object + to**-inf | advise, urge, persuade, remind, warn, encourage, beg, invite, order, forbid, instruct, implore |
| verb + **-ing** / **having + pp** | deny, admit (to), suggest, recommend, regret, mention, propose |
| verb + **preposition + -ing** | apologise **for**, insist **on**, object **to**, confess **to**, boast **about/of** |
| verb + **object + preposition + -ing** | accuse sb **of** · blame sb **for** · congratulate sb **on** · criticise sb **for** · forgive sb **for** · prevent/stop/deter/discourage sb **from** · suspect sb **of** · thank sb **for** · warn sb **against/about** · charge sb **with** · talk sb **into/out of** · dissuade sb **from** |
| verb + **that** + subjunctive/should | demand, insist, propose, recommend, suggest, request |

✗ *accused him **for*** · ✗ *suggested **me to*** · ✗ *apologised **to have done*** · ✗ *denied **to take*** · ✗ *explained **me*** → ✓ *explained **to me***

### 4.8 Other C2 verb structures

- **be to + inf** (formal arrangement/instruction): *You **are to** report at 9.* / *The PM **is to** visit Kraków.*
- **be on the point/verge/brink of + -ing / NP**; **be about to**; **be due to**; **be set to**
- **only to + inf** (disappointing result): *He rushed to the station, **only to find** the train had gone.*
- **Absolute constructions:** ***It being** a holiday, the shops were closed.* / ***Weather permitting**, we'll go.*
- **Dangling participles (formal error):** ✗ *Walking home, the rain started.* ✓ *Walking home, **I** got caught in the rain.*

## MODULE 5 — CLEFT SENTENCES & EMPHASIS

### 5.1 It-cleft

**Formula:** `It + be + FOCUS + that/who + rest of clause`

| Focus | Example |
|---|---|
| Subject (person) | *It was **John who/that** broke it.* |
| Object | *It was **the vase that** he broke.* |
| Time / place / reason | *It was **in 1066 that**…* / *It was **because he was ill that** he resigned.* |
| *not until* | *It was **not until 1928 that** women got equal voting rights.* |
| *only when* | *It was **only when** I saw her **that** I understood.* |
| *not X but Y* | *It is **not money but time that** I lack.* |

**Rules:** use **that** after adverbials (✗ *It was in Paris **where** we met*). Formal agreement: *It is **I who am** responsible* (informal: *It's me who's*). Focus a **verb**? → impossible in it-clefts; use a wh-cleft.

### 5.2 Wh-cleft (pseudo-cleft) & variants

| Model | Example |
|---|---|
| What + clause + be + focus | ***What I need is** a holiday.* |
| What + subject + did + was + (to) + bare inf | ***What she did was (to) call** the police.* |
| What happened was (that) … | ***What happened was that** the bus broke down.* |
| All (that) + clause + be | ***All I did was ask** a question.* ✗ *All **what** I did* |
| The thing / The one thing / The only thing | ***The last thing I want is** an argument.* |
| The reason (why) … is **that** | ✗ *The reason is **because**…* |
| The person who / The place where / The day when | *Kraków is **the place where** I was born.* |
| Reversed | ***A holiday is what** I need.* / ***That's why**…* |

**Native pitfalls:** ✗ *What **does** irritate me is…* (no *do*-support in subject wh-clauses) · ✗ *All I did was **asked/asking*** · ✗ *All **what** I want* (Polish *wszystko, co*).

### 5.3 Other emphatic devices

- **Emphatic *do*:** *I **did** tell you!* / ***Do** sit down.* / *She **does** look tired.*
- **Fronting:** *That **I** can't accept.*
- **Intensifiers:** *no doubt **whatsoever** · not **in the least** · not **the slightest** idea · **the very** man · **by far** the best · **easily** the best · **much/far** better* · *What **on earth**…? · Why **ever**…?*
- **So/such:** *so + adj* · *such (a) + adj + noun* · *so much/many/few/little + noun* · *so much so that* · *to such an extent that* · ✗ *so good advice* → ✓ *such good advice*

### 6.5 People, titles, groups

- Titles + name: *King Charles, President Lincoln* (no article) vs ***the** King, **the** President, **the** Prince of Wales*.

***an** hour, **an** honest man, **an** heir, **an** MP, **an** MBA, **an** X-ray, **an** 18th-century house, **an** NHS hospital* · ***a** university, **a** European, **a** one-off, **a** UFO, **a** U-turn, **a** NATO summit, **a** historic day* (*an historic* is dated).

# PART III — TASK TOOLKITS

## III.A — Key Word Transformations (Task A)

### A.1 The 7-step routine (60 seconds)

1. **Read both sentences** — what's already written *after* the gap often dictates the structure (*than* → *No sooner*; *that* → cleft/*so/such*; *did I* → inversion done for you).
2. **Identify the key word's natural partners** (*ACCORD* → *of one's own accord*; *BRUNT* → *bear the brunt of*).
3. **Check every piece of meaning moved across:** tense, negation, time, agent, intensity (*very nearly*, *never*, *all*).
4. **Key word unchanged**, form and spelling identical.
5. **Count: ≤ 6 words incl. the key word.**
6. **Read the whole sentence aloud in your head** — does it join grammatically to the words after the gap?
7. **Spell-check letter by letter.**

## III.C — Gramatykalizacja & Hangman (Task C)

### C.1 Gramatykalizacja routine
1. Keep the **order** of the given words (standard Polish-exam convention).
2. Change **form** as needed (tense, voice, infinitive/gerund, comparison).
3. **Add** the missing grammar words (auxiliaries, articles, prepositions, *not*).
4. Check the clue words around the gap: *for three years* → perfect; *by the time* → past perfect; *Not until* → inversion.

### C.2 Hangman (wisielec) routine
1. Use the **letter count** — it eliminates BrE/AmE variants (*manoeuvre* 9 / *maneuver* 8) and misspellings (*mischievious* ✗ 12 letters).
2. Decide the **meaning** from context first, then fit the visible letters.
3. Spelling is all-or-nothing. Keep a personal list of words you mis-spell.

**High-risk spellings:** accommodate · acquiesce · bureaucracy · conscientious · connoisseur · embarrass · entrepreneur · fluorescent · guarantee · harass · idiosyncrasy · liaison · manoeuvre · millennium · minuscule · mischievous · occurrence · perseverance · privilege · questionnaire · rhythm · supersede · threshold · ubiquitous · unanimous · withhold

## III.D — Multiple Choice (Task D)

### D.1 Strategy

# PART VI — ANSWER KEYS

## KEY A — Key Word Transformations

> Word counts include the key word. ✓ = target answer · (✓) = also acceptable · ✗ = why the native-sounding version fails.

**1.** **sooner had the minister finished** (5)
✗ *sooner **the minister had** finished* — no inversion. ✗ *…finished **when*** — *when* belongs to *hardly/scarcely*; *no sooner* takes **than** (already given). *No sooner did the minister finish* appears in some grammars but the past perfect is the expected form — don't gamble.

**2.** **take our health for granted** (5)
✗ *take our health **as** granted* · ✗ *take our health granted* · *take for granted our health* — the object goes **between** *take* and *for granted* unless it is long.

**3.** **wish I had taken** (4)
✗ *wish I **took*** (present meaning) · ✗ *wish I **would have** taken* (very common in speech, non-standard) · ✗ *wish I **would take*** (*wish + would* is for other people/things).

**4.** **are thought to have been** (5)
✗ ***is** thought…* — *there* agrees with *hundreds of people* · ✗ ***were** thought…* — original reporting verb is present (*It is thought*) · ✗ *are thought **to be*** — the trapping was earlier.

**5.** **of his own accord** (4)
✗ ***on** his own accord* — the classic native error · ✗ *by his own accord* · ✗ *of his accord* (*own* is required).

**6.** **had her flat broken into** (5)
✗ *had **broken into her flat*** — now Sarah is the burglar! · ✗ *had her flat **broken*** — *break into* = burgle; the particle **into** must stay.

**7.** **would rather you did not mention** (6)  (✓ *would rather you didn't mention* = 5, contraction counts as one word)
✗ *would rather you **do not*** — different subject needs the **past** · ✗ *would rather you **not** mention* — AmE subjunctive, not the expected answer · ✗ *would rather **that** you did not mention* — 7 words.

**8.** **did the fraud become apparent** (5)
✗ *the fraud became apparent* — *Only when…* forces inversion in the main clause · ✗ ***became the fraud** apparent* — lexical verbs need *did* · ✗ *did the fraud **became***.

**9.** **need not have booked** (4)  (✓ *needn't have booked*)
✗ *did not need to book* — doesn't say we **did** book; the original does · ✗ *need not **to** have booked* · ✗ *did not need to **have** booked*.

**10.** **it not been for** (4)
✗ ***Hadn't** it been for* — inverted conditionals are never contracted · ✗ *it been **not** for* · ✗ *not it been for*.

**11.** **is at odds with** (4)
✗ *is **in** odds with* · ✗ *is at **odd** with* · ✗ *is at odds **to***.

**12.** **All I did was ask** (5)  (✓ *All I did was to ask* = 6)
✗ *All **what** I did* — calque of *wszystko, co*; use *all (that)* · ✗ *was **asked*** / *was **asking*** — after *All/What … did was*, use the (bare) infinitive.

**13.** **occurred to me to check** (5)
✗ *occurred **me*** — *occur **to** sb* · ✗ *occurred to me **checking*** · ✗ *occurred to me that I should check* — 7 words.

**14.** **Little did Kate know** (4)  (✓ *realise / suspect / imagine*)
✗ *Little **Kate knew*** — no inversion · ✗ *Little did Kate **knew*** · Use **Kate**, not *she*: the name appears nowhere else in the new sentence.

**15.** **could not possibly have written** (5)  (✓ *cannot possibly have written* = 4)
✗ ***must not** have written* — AmE deduction; in BrE-based keys *must not* = prohibition · ✗ *cannot possibly have **wrote*** — dialect participle.

**16.** **suggested that the meeting be** (5)  (✓ *suggested (that) the meeting should be* · ✓ *suggested the meeting be*)
✗ *suggested the meeting **to be*** — *suggest* never takes object + *to*-inf · ✗ *suggested that the meeting **was*** — now it means she *claimed* it had been postponed · ✗ *…**is** postponed* — informal indicative, wrong tense.

**17.** **were kept in the dark about** (6)  (✓ *were left in the dark about*)
✗ *were kept in **dark*** — article needed · ✗ *in the dark **of*** · ✗ *in the darkness*.

**18.** **Try as he might** (4)  (✓ *Try as he may*)
✗ *As he might try* · ✗ *Trying as he might* · ✗ *Try **as hard as** he might* — a blend of two structures; avoid.

**19.** **high time you started** (4)  (✓ *high time for you to start* = 6)
✗ *high time you **start*** · ✗ *high time you **should** start* · ✗ *high time you **had started***.

**20.** **bore the brunt of** (4)  (✓ *took the brunt of*)
✗ ***beared** the brunt* — past of *bear* is **bore** · ✗ *the **brunts** of*.

**21.** **no time were the prisoners informed** (6)
✗ *no time **the prisoners were*** — no inversion · ✗ ***In** no time…* — means "very quickly"; never inverts · ✗ *no time had the prisoners been informed* — 7 words and a tense shift.

**22.** **accused Mr Hale of leaking** (5)  (✓ *accused Mr Hale of having leaked* = 6)
✗ *accused Mr Hale **for** leaking* (*blame sb **for***, *accuse sb **of***) · ✗ *accused Mr Hale **to have** leaked* · ✗ *accused Mr Hale **that** he leaked* · Use the name: *him* would have no reference.

**23.** **Had I accepted the job** (5)  (✓ *If I had accepted the job* = 6)
Mixed conditional: past condition → present result (*would not still be living*).
✗ *If I **would have** accepted* · ✗ *If I **accepted*** — 2nd conditional = wrong time.

**24.** **was not until the 1940s** (5)  (✓ *wasn't until the 1940s*)
✗ *was **only** until* · ✗ *was not **before*** · ✗ *not until **1940s*** — decades take *the*.

**25.** **turned a blind eye to** (5)
✗ *turned a blind eye **on*** · ✗ ***closed** a blind eye* · ✗ *turned **blind eye***.

**26.** **Were the government to raise** (5)
✗ ***Was** the government to raise* — only *were* inverts · ✗ *Were the government **raise*** — needs *to* · ✗ *Should the government raise* — correct idea but doesn't use **WERE**.

**27.** **me none the wiser** (4)
✗ *me none **wiser*** · ✗ *me none the **wise*** · ✗ *me **not** the wiser*.

**28.** **in the face of strong** (5)
✗ ***on** the face of* — *on the face of it* = "apparently", a different idiom · ✗ *in face of* — less standard; write *in the face of*.

**29.** **was on the brink of** (5)  (✓ *was teetering on the brink of* = 6 · ✓ *was on the verge of* — but doesn't use BRINK)
✗ *on the brink **to*** · ✗ *on **a** brink of* · ✗ ***at** the brink of*.

**30.** **fell short of our** (4)
✗ ***felt** short of* — *fall–fell–fallen* vs *feel–felt* · ✗ *fell short **from*** · ✗ *were short of our* — means "lacked", different meaning.
